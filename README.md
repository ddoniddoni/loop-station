# Loop Station

브라우저에서 녹음하고 반복하며 소리를 쌓는 웹 루프스테이션을 만들기 위한 초기 프로젝트입니다.

**현재 범위:** Radix 기반 Stitch 콘솔에서 8개 트랙의 1/2/4/8마디 PCM 녹음·동시 반복·오버더빙·로컬 자동 저장을 구현했습니다. 실제 장치 녹음·청취와 저장 복구의 브라우저 검증은 아직 하지 않았습니다. 트랙별 볼륨·팬·Mute·Solo, 루프 마스터 볼륨·음소거, 실제 PCM 출력 미터와 설정 저장까지 연결했습니다. 파일 백업·클라우드는 준비 중입니다.

상단 `AUDIO`에서 오디오를 시작하고, `입력 설정`에서 마이크를 연결한 뒤 원하는 트랙의 `녹음 길이`에서 1·2·4·8마디를 선택하고 `RECORD`를 누릅니다. 기본은 4마디이며 다음 마디부터 선택한 길이를 녹음하고 자동으로 반복합니다. 다른 트랙을 녹음해도 기존 루프는 계속 재생합니다. 녹음·편집은 한 번에 한 트랙씩 진행하며, 각 트랙에서 취소·정지·재시작과 비운 루프 복구를 제공합니다. 모바일에서는 Bank 1–4 / 5–8로 전환합니다.

상단 BPM을 눌러 템포 설정을 열고 `TAP · 템포 맞추기`를 4분음표 간격으로 누르면 BPM 입력칸에 제안값을 채웁니다. 두 번부터 최근 네 간격의 평균을 사용하며 `설정 적용`을 눌러 공통 오디오 시계에 반영합니다. 6/8·7/8에서도 4분음표 기준입니다. 지원 범위는 40~240 BPM이며 250ms보다 빠른 입력은 제외하고 1.5초 넘게 쉬면 다음 Tap부터 다시 셉니다. 수동 BPM 입력·설정 적용·설정창 닫기·오디오/잠금 상태 변경 때 Tap 기록을 초기화합니다. 설정창을 다시 열면 현재 적용값을 보여 줍니다. 오디오가 준비되지 않았거나 루프·복구 이력·녹음/편집·저장소 작업이 있으면 Tap과 템포 변경을 잠급니다. 실제 브라우저 동작은 아직 미검증입니다.

오디오 시작은 Worklet의 첫 처리 응답을 확인한 뒤 준비 완료로 표시하도록 구현했습니다. 준비 응답이 15초 안에 오지 않으면 실패를 안내하고 자원을 정리합니다. 시작 중 취소할 수 있고, 종료가 끝날 때까지 재시작을 막으며 종료 실패 시 재시도 버튼을 제공합니다. 오디오 시작만으로 마이크를 요청하지 않습니다. 마이크 없이 개발용 테스트 신호를 켜고 끌 수 있습니다. 이 수명 처리의 실제 브라우저 검증은 아직 보류 중입니다.

반복 중 `오버더빙 · 1회`를 누르면 다음 루프부터 한 바퀴 덧녹음합니다. 취소하거나 입력이 끊기면 기존 루프를 유지합니다. `Undo`와 `Redo`는 직전 오버더빙 한 번을 되돌리고 다시 적용합니다. 재생 중에는 다음 루프 경계에서 적용하고, 대기 중인 예약은 취소할 수 있습니다.

**상단에 `이 기기에 저장됨`이 표시된 변경은 새로고침 후 복구됩니다.** 8개 트랙의 PCM·공통 BPM·박자와 트랙별 Undo/Redo·비우기 복구 이력과 팬·루프 마스터를 포함한 믹서 설정을 하나의 프로젝트로 IndexedDB에 보관합니다. 기존 v1 단일 트랙, v2 8트랙, v3 믹서, v4 스테레오 믹서 저장본도 불러옵니다. 이전 저장본을 열기만 하면 원본은 유지되고, 다음 변경을 저장할 때 서로 다른 루프 길이를 지원하는 v5로 전환합니다. 복구된 루프는 직접 오디오를 시작하고 재생해야 소리가 납니다. 저장 상태를 누르면 실패 원인과 재시도를 확인할 수 있습니다. `저장 없이 계속`을 선택하면 기존 저장본은 유지하고 이후 변경은 이 탭에만 남깁니다.

각 트랙은 모노이고 길이를 독립적으로 선택합니다. 녹음·편집·저장 중이거나 루프가 있으면 길이 선택을 잠급니다. 길이를 바꾸려면 먼저 루프를 비우며, 복구하면 원래 길이와 이력이 돌아옵니다. 녹음 전 선택은 이 탭에만 유지되고, 녹음된 루프 길이는 저장·복구됩니다. 루프나 비우기 복구 이력이 있으면 BPM·박자를 고정합니다. 작업 버퍼는 트랙당 32MiB·프로젝트 전체 128MiB 내에서 제한합니다. 긴 녹음이나 복구 이력으로 한도를 넘으면 녹음을 거절하고 기존 소리를 유지합니다. 트랙과 루프 마스터 볼륨은 −60~+6 dB로 조절합니다. 모노 트랙을 팬으로 좌우 배치하고 마스터 게인 뒤에서 최종 스테레오 출력을 ±1로 제한합니다. 기본 마스터는 기존 0.5 게인에 해당하는 약 −6.02 dB입니다. 녹음 원본에는 이 제한을 적용하지 않습니다.

믹서의 `M`은 재생 위치를 유지한 음소거, `S`는 솔로입니다. 여러 솔로를 함께 선택할 수 있고 Mute가 우선합니다. 페이더를 움직이면 10ms 게인 램프로 음량을 바꾸며 조작 종료 시 자동 저장합니다. 녹음·편집과 저장 중에는 믹서를 잠급니다. 모바일 Mixer 화면에서도 Bank 1–4 / 5–8을 바꿀 수 있습니다. 트랙 미터는 볼륨·팬 적용 후 레벨, 마스터 L/R은 최종 출력의 피크·RMS를 표시합니다. HOLD와 과부하 경고는 초기화 버튼으로 지울 때까지 유지됩니다. 오디오를 끄거나 중단하면 측정 대기로 돌아갑니다. 루프 마스터와 미터에는 마이크 모니터·메트로놈·테스트 신호가 포함되지 않습니다. 최종 출력 제한은 하드 클리핑이며 음질을 보장하는 리미터가 아닙니다.

녹음 도중 종료한 입력, 아직 저장되지 않은 변경은 사라질 수 있습니다. 브라우저 데이터 삭제·비공개 모드 종료에도 저장본을 잃을 수 있으며, 파일 백업은 준비 중입니다. 다른 탭에서 저장하면 편집을 멈추고 안내하며, 충돌하는 저장은 기존 저장본을 덮어쓰지 않습니다.

## 실행

Node.js 24 LTS를 권장합니다(`.nvmrc`). Node.js 26 안정 버전도 허용합니다. 패키지 관리자는 npm 11입니다.

```bash
cd /Users/ddoni/dev/loop-station
# nvm을 사용하는 경우: nvm use
npm ci
npm run dev
```

http://localhost:3000 에서 확인합니다. 환경변수나 외부 계정은 필요하지 않습니다. 의존성이 설치되어 있으면 `npm run dev`만 실행하면 됩니다.

## 검사

```bash
npm run lint
npm run typecheck
npm run test
npm run build
npx playwright install chromium
npm run test:e2e
```

E2E는 빌드된 앱을 전용 포트 3108에서 실행하고 종료합니다. 기존 서버를 재사용하지 않습니다. `test:audio`는 시간 변환과 PCM 루프 코어의 합성 입력 테스트이며, 실제 마이크·Worklet 로딩·실청취 검증을 대신하지 않습니다. 새 PCM 테스트는 사용자 요청에 따라 아직 실행하지 않았습니다. 단위 테스트의 관찰 모드는 `npm run test:watch`입니다.

## 구조

```text
src/app/                 App Router와 초기 화면
src/lib/i18n/            한국어 UI 문구
src/audio/transport/     React/DOM에 의존하지 않는 시간 변환
src/audio/loop/          공통 시계의 8트랙 PCM 녹음·반복과 트랙별 편집 이력
src/audio/storage/       IndexedDB 세션 저장·무결성 확인·충돌 감지
tests/audio/             시간 변환·PCM 코어 테스트
tests/e2e/               production 브라우저 테스트
docs/                    상세 명세와 실제 진행 기록
docs/plan/               Phase별 로드맵과 다음 개발 작업
```

`build`와 `dev`는 `build:audio`로 AudioWorklet을 먼저 번들링합니다. 개발 중 Worklet 코드를 바꿀 때는 별도 터미널에서 `npm run watch:audio`를 실행하고 오디오를 다시 시작합니다. 로컬 저장은 접속 주소별로 분리됩니다. 예를 들어 localhost:3000의 저장본은 127.0.0.1:3108에서 공유되지 않습니다.

각 Phase 개발 전에 최신 develop 기준으로 작업 브랜치를 만들고, 개발 종료 후 허용된 검사와 문서 정리를 거쳐 관련 변경을 커밋·푸시합니다. 이는 2026-09-26 사용자 상시 지시입니다. merge·PR·배포 등은 별도 요청을 따르며, 테스트 중단 상태에서는 미실행 사실과 남은 검증을 기록합니다.
